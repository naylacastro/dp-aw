Essa atividade é da disciplina de Autoria Web e faz parte da Semana 26 do Bimestre 3.
A ideia foi trabalhar a tipografia de forma simples, fazendo com que os títulos se adaptem ao tamanho da tela.
Foram usados os títulos H1, H2 e H3, que mudam de tamanho conforme o viewport.
Para isso, foi utilizada a unidade vw junto com calc(), evitando que o texto fique exagerado.
Também foi usado o clamp() para limitar o tamanho mínimo e máximo da fonte.
A página foi feita de forma simples, usando HTML e CSS, apenas para atender ao que a atividade pede.
