Esta atividade consiste na criação de uma mini landing page semântica, feita com HTML e CSS.
O objetivo foi aplicar tags semânticas, listas e formulários, criando uma estrutura visual agradável e organizada.
A página apresenta seções simples, como "Sobre", "Benefícios" e "Contato", para simular um site real.
O design foi pensado para ser limpo, intuitivo e de fácil leitura.
