Nesta atividade, desenvolvi uma página utilizando HTML semântico,objetivo foi estruturar o conteúdo de forma clara, acessível e organizada, facilitando a leitura tanto para usuários quanto para navegadores. Cada seção da página foi pensada para ter um propósito específico, tornando a informação mais fácil de entender. O layout é simples e acolhedor, com cores suaves e sem imagens, mantendo o foco no conteúdo textual e na experiência do usuário.
