# Atividade 1 — Estrutura Básica

Nesta atividade, criei uma página web simples utilizando HTML e CSS. A página contém um cabeçalho com o nome do site e menu de navegação simples , um main com um pequeno texto, e um rodapé com créditos. Essa estrutura segue os conceitos de semântica e estilização externa pedidos no 2º bimestre.
